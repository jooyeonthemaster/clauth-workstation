계정별 사용량
상태와 실행 사용량은 데몬이 마지막으로 기록한 값입니다. 프로세스와 상태 갱신 시간을 함께 확인하세요.
페이블은 모델별 주간 사용 창입니다. 제공되지 않는 사용 창은 미확인으로 표시합니다.
추정값은 최근 사용 기록에 따른 참고값입니다. 계정별 잔량 합계는 동일한 절대 사용량을 뜻하지 않습니다.
기본 계정 전환 버튼은 다음 실행에서 사용할 기본 계정을 바꿉니다. 이미 실행 중인 clauth start 세션과 VS Code 대화는 각자의 계정을 사용합니다.
세션 자동 전환이 필요하면 설치 폴더에서 node src/cli.mjs start <프로필이름>으로 새 세션을 시작하세요. 각 세션의 전환 체인은 독립적으로 동작합니다.
파일 일치는 실행 중인 세션이나 macOS 키체인이 같은 계정이라는 보장은 아닙니다. 새 세션에서 계정을 확인하세요.
